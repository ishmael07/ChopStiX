# ChopStiX

Chopsticks, the hand game, built like chess.com. Play it at **https://ishmael07.github.io/ChopStiX/**

- **Play online:** get matched with someone near your rating for a rated, timed game. The server runs the game: it checks every move, keeps the clocks, and rates the result
- **Daily puzzle and streaks:** everyone gets the same "win in N" puzzle each day; solving it keeps your streak going. More rated puzzles with their own puzzle rating, all checked by the server against the solver
- **Leaderboards:** rating, this week's gains, puzzles, streaks, and friends
- **Friends:** add by username, see who's online, challenge them to a rated game
- **Badges** earned from your record, shown on your profile
- **Chat** in online games, with quick phrases, filtering and mute
- **Play the computer:** five bots, from Pip (400) to Sensei, who plays perfectly (the game is solved)
- **Play a friend:** send a link and play live, peer to peer, no account needed
- **Local:** two players on one device
- **2D and 3D boards** with real rigged hands, camera angles, drag-to-tap and in-place splitting
- **Rules:** Classic, Lunch Table (free swaps), or Custom
- **After the game:** accuracy, graded moves, and replay

Play as a guest (name and rating saved on this device) or create an account for a server-checked Elo rating and a public profile.

## Run locally

```bash
npm install
npm run dev
```

Accounts and online play need a Supabase project: copy `.env.example` to `.env.local` and run the SQL in `supabase/migrations/` in order. `0004_puzzle_data.sql` is generated by `npx tsx scripts/gen-puzzles.ts`. Without it the app runs in guest-only mode. Accounts sign in with a username and password, so turn off **Confirm email** under Authentication → Sign In / Providers → Email.

`npm run build` outputs a static site in `dist/`. Pushing to `main` deploys to GitHub Pages.
